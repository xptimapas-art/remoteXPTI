# Política de versões

Regra definida pelo proprietário do projeto em 14/10/2026:

- Estáveis: incrementar o número do meio e manter a última casa em zero.
  Exemplo: `2.2.0`, depois `2.3.0`.
- A última casa é reservada aos testes beta. As versões beta devem ser
  publicadas como pré-release, disponíveis apenas no canal de beta testers.
- Não publicar versões de teste como estáveis.
- Publicações no GitHub exigem autorização do proprietário.

A publicação estável `2.2.0` foi explicitamente solicitada nesta sessão.
